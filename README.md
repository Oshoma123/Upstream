## How the number is kept honest

`n` is never typed by hand. `ledger/ledger.py` counts it from the GitHub API:
a contribution counts only when an upstream maintainer has **merged** it.
Open PRs, PRs closed without merge, and issues are all reported alongside it
and never added to it. Re-run `python ledger/ledger.py && python ledger/render.py`
to refresh.

## How contributions are made

Every contribution follows [`docs/PROTOCOL.md`](docs/PROTOCOL.md): evidence
first, a duplicate check, a check against current upstream, upstream's own
checks run locally, AI assistance disclosed, credit only for real work.
Each one lives in `contributions/NNNN-*/` with its evidence, a reproducible
`verify.sh`, the exact diff, the PR text and a `STATUS.json`.

Candidates in progress: [`backlog/BACKLOG.md`](backlog/BACKLOG.md).
